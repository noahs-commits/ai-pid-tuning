# AI PID Tuning

A small 1D simulation environment for experimenting with PID controllers and,
eventually, AI/RL-based auto-tuning.

The body moves along one vertical axis.  A thrust action, weight, linear drag
and a fractal Perlin noise disturbance determine its acceleration.  The
setpoint can be fixed or driven by its own noise field.

## Setup

```bash
python3 -m venv .venv
.venv/bin/pip install -e .
# optional: plotting and CMA-ES tuning
.venv/bin/pip install -e '.[plot,tuning]'
```

## Physics

Every step

```text
drag_force   = -drag * velocity
disturbance  = disturbance_strength * perlin(time * disturbance_frequency)
thrust_force = clip(action, -1, 1) * thrust

accel    = (thrust_force - weight + drag_force + disturbance) / mass
velocity += accel * dt
position += velocity * dt
```

The integration is semi-implicit Euler.  Positive position and thrust point
upward.

`weight` is a force in newtons, not a mass.  Change `mass` to alter how
strongly forces affect acceleration.

## Setpoint and perturbations

Both disturbance and (optionally) the setpoint are generated by
`FractalPerlinNoise`, a seeded 1D Perlin noise summed over several octaves.

```python
from pid_env import FractalPerlinNoise

noise = FractalPerlinNoise(
    seed=0,
    octaves=4,        # detail layers
    persistence=0.5,  # amplitude per octave
    lacunarity=2.0,   # frequency per octave
    frequency=1.0,
)
value = noise.sample(3.5)  # roughly [-1, 1]
```


## CMA-ES tuning

pid_env.tuning.tune searches for optimal kp, ki, kd. from a given EnvironmentConfig

```python
from pid_env import EnvironmentConfig, LossHyperparameters
from pid_env.tuning import CMAESConfig, tune

if __name__ == "__main__":
    result = tune(
        EnvironmentConfig(thrust=35.0, weight=12.0, drag=0.8),
        LossHyperparameters(1.0, 0.1, 0.01),
        CMAESConfig(
            max_evaluations=800,
            seeds=(0, 1, 2),
            validation_seeds=(1000, 1001),
            popsize=12,
            workers=4,
        ),
    )

    print(result.best_gains, result.best_loss, result.validation_loss)
```
